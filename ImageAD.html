📸 Image Display & Download Guide 📸 इमेज दिखाना और डाउनलोड करना गाइड

Introduction

परिचय

This page shows how to display an image and how to let users download it using plain HTML — no JavaScript, no server required.

यह पेज बताता है कि इमेज कैसे दिखाएँ और उपयोगकर्ताओं को कैसे डाउनलोड करने दें — सिर्फ HTML से, बिना JavaScript, बिना सर्वर।

1. Live Demo (See It Working)

1. लाइव डेमो (काम करते देखें)

⬇️ Download Image ⬇️ इमेज डाउनलोड करें
💡 What's happening? The <img> tag shows the picture. The <a download> tag saves it to the user's device. 💡 क्या हो रहा है? <img> टैग चित्र दिखाता है। <a download> टैग उसे उपयोगकर्ता के डिवाइस पर सेव करता है।

2. Step 1 — Display an Image

2. चरण 1 — इमेज दिखाना

Use the <img> tag. It has only 3 important attributes:

<img> टैग का उपयोग करें। इसमें केवल 3 ज़रूरी एट्रिब्यूट हैं:

<img src="image.jpg" alt="My Image" width="320">
Attributeएट्रिब्यूट Meaningअर्थ
src Path or URL of the image fileइमेज फ़ाइल का पाथ या URL
alt Text shown if image fails / for screen readersइमेज न दिखे तो टेक्स्ट / स्क्रीन रीडर के लिए
width Width in pixels (height auto-scales)चौड़ाई पिक्सेल में (ऊँचाई अपने आप स्केल)

Two ways to give the image source

इमेज सोर्स देने के दो तरीके

A) Local file (same folder):A) लोकल फ़ाइल (उसी फ़ोल्डर में):

<img src="image.jpg" alt="Local image">

B) Online URL:B) ऑनलाइन URL:

<img src="https://example.com/photo.jpg" alt="Online image">
⚠️ Folder rule: If the image is in the same folder as your HTML file, write only the filename. If it's inside a folder called images/, write images/image.jpg. ⚠️ फ़ोल्डर नियम: अगर इमेज HTML फ़ाइल के उसी फ़ोल्डर में है, तो सिर्फ फ़ाइल नाम लिखें। अगर images/ नाम के फ़ोल्डर में है, तो images/image.jpg लिखें।

3. Step 2 — Add a Download Button

3. चरण 2 — डाउनलोड बटन जोड़ना

Use the <a> tag with the download attribute:

<a> टैग के साथ download एट्रिब्यूट का उपयोग करें:

<a href="image.jpg" download="my-photo.jpg">Download</a>
Partभाग Purposeउद्देश्य
href="image.jpg" File to downloadजिस फ़ाइल को डाउनलोड करना है
download Tells browser: save the file, don't open itब्राउज़र को कहता है: फ़ाइल सेव करो, खोलो नहीं
download="my-photo.jpg" Custom filename saved on user's deviceउपयोगकर्ता के डिवाइस पर सेव होने वाला कस्टम नाम
✅ Best practice: Always write a filename inside download="...". Otherwise some browsers (especially mobile) ignore the download and open the image instead. ✅ सर्वोत्तम प्रथा: हमेशा download="..." में फ़ाइल नाम लिखें। वरना कुछ ब्राउज़र (खासकर मोबाइल) डाउनलोड को नज़रअंदाज़ करके इमेज खोल देते हैं।

4. Step 3 — Combine Both (Final Code)

4. चरण 3 — दोनों को जोड़ें (अंतिम कोड)

<!-- Show the image -->
<img src="image.jpg" alt="My Image" width="320">

<br><br>

<!-- Download link -->
<a href="image.jpg" download="my-image.jpg">
    ⬇️ Download Image
</a>

That's it! Just 2 elements — one shows the image, one saves it.

बस इतना ही! सिर्फ 2 एलिमेंट — एक इमेज दिखाता है, दूसरा उसे सेव करता है।

5. Bonus — Fallback if Image Missing

5. बोनस — इमेज न मिले तो विकल्प

If the image file doesn't exist, the browser shows a broken icon. Fix it with onerror:

अगर इमेज फ़ाइल नहीं है, तो ब्राउज़र टूटा आइकन दिखाता है। onerror से ठीक करें:

<img src="image.jpg"
     alt="My Image"
     width="320"
     onerror="this.src='https://via.placeholder.com/320x200?text=No+Image'">
💡 If image.jpg is missing, it automatically loads the placeholder instead of showing a broken icon. 💡 अगर image.jpg मौजूद नहीं है, तो टूटा आइकन दिखाने के बजाय अपने आप प्लेसहोल्डर लोड हो जाता है।

6. Common Mistakes

6. सामान्य गलतियाँ

❌ Wrong❌ गलत ✅ Correct✅ सही
<img src="image.jpg"> <img src="image.jpg" alt="Photo">
<a href="image.jpg" download> <a href="image.jpg" download="my.jpg">
Image and HTML in different folders without pathइमेज और HTML अलग फ़ोल्डर में बिना पाथ src="images/image.jpg"
Using height only (distorts image)सिर्फ height देना (इमेज बिगड़ती है) width="320" (height auto)(ऊँचाई अपने आप)

7. Quick Summary

7. त्वरित सारांश

  • Show image → <img src="file.jpg" alt="text">
  • इमेज दिखाएँ → <img src="file.jpg" alt="text">
  • Download image → <a href="file.jpg" download="name.jpg">
  • इमेज डाउनलोड करें → <a href="file.jpg" download="name.jpg">
  • Fallback if missing → onerror="this.src='placeholder.jpg'"
  • न मिले तो विकल्प → onerror="this.src='placeholder.jpg'"
  • Keep files in the same folder (or give correct path).
  • फ़ाइलें एक ही फ़ोल्डर में रखें (या सही पाथ दें)।
