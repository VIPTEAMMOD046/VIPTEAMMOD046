A complete beginner-to-advanced walkthrough of HTML (structure) and PHP (server-side logic). HTML (संरचना) और PHP (सर्वर-साइड लॉजिक) की शुरुआती से उच्च स्तर तक पूरी जानकारी।

PART 1: HTML (HyperText Markup Language) भाग 1: HTML (हाइपरटेक्स्ट मार्कअप लैंग्वेज)

HTML is the skeleton of a web page. It defines structure and content. HTML किसी वेब पेज का ढाँचा है। यह संरचना और सामग्री को परिभाषित करता है।

A. Basic HTML Document Structure A. HTML दस्तावेज़ की मूल संरचना 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>
</head>
<body>
    <h1>Hello World</h1>
</body>
</html>
  • <!DOCTYPE html> → tells browser it's HTML5
  • <!DOCTYPE html> → ब्राउज़र को बताता है कि यह HTML5 है
  • <html> → root element
  • <html> → रूट एलिमेंट
  • <head> → metadata (not visible)
  • <head> → मेटाडेटा (दिखाई नहीं देता)
  • <body> → visible content
  • <body> → दिखाई देने वाली सामग्री

PART 2: PHP (PHP: Hypertext Preprocessor) भाग 2: PHP (PHP: हाइपरटेक्स्ट प्रीप्रोसेसर)

PHP is a server-side language — it runs on the server and sends HTML to the browser. PHP एक सर्वर-साइड भाषा है — यह सर्वर पर चलती है और ब्राउज़र को HTML भेजती है।

A. Basic PHP Syntax A. PHP की मूल सिंटैक्स 

<?php
    echo "Hello World";
?>
  • Starts with <?php, ends with ?>
  • <?php से शुरू होता है, ?> पर खत्म होता है
  • Statements end with ;
  • हर स्टेटमेंट ; पर समाप्त होता है
  • Can be mixed with HTML
  • HTML के साथ मिलाकर लिखा जा सकता है

B. Variables & Data Types B. वेरिएबल और डेटा प्रकार 

<?php
    $name = "John";       // string
    $age = 25;            // integer
    $price = 9.99;        // float
    $isActive = true;     // boolean
    $items = [1, 2, 3];   // array
    $user = null;         // null
?>
  • Variables start with $
  • वेरिएबल $ से शुरू होते हैं
  • No type declaration needed (loosely typed)
  • टाइप घोषित करने की आवश्यकता नहीं (लूज़ली टाइप्ड)

C. Operators C. ऑपरेटर 

<?php
    $a = 10 + 5;      // 15
    $b = 10 % 3;      // 1 (modulus)
    $c = "Hi" . " there";   // concatenation with .

    // Comparison
    $x == $y;   // equal value
    $x === $y;  // equal value AND type
    $x != $y;   // not equal
    $x > $y;    // greater than
?>

D. Conditionals D. शर्तें (Conditionals) 

<?php
    if ($age >= 18) {
        echo "Adult";
    } elseif ($age >= 13) {
        echo "Teen";
    } else {
        echo "Child";
    }

    // Switch
    switch ($color) {
        case "red": echo "Stop"; break;
        case "green": echo "Go"; break;
        default: echo "Unknown";
    }

E. Loops E. लूप्स 

<?php

F. Functions F. फ़ंक्शन 

<?php

        return "Hello, $name!";

    // Default parameter

G. Arrays G. एरे (Arrays) 

<?php
    // Indexed
    $colors = ["red", "green", "blue"];
    echo $colors[0];    // red

    // Associative
    $user = [
        "name" => "John",
        "age" => 25,
        "email" => "john@example.com"
    ];
    echo $user["name"];   // John

    // Useful functions
    count($colors);        // 3
    array_push($colors, "yellow");
    array_keys($user);
    array_values($user);
?>

B. Processing a Form B. फ़ॉर्म को प्रोसेस करना

form.html

<form action="process.php" method="POST">
    <input type="text" name="name" placeholder="Your name">
    <input type="email" name="email" placeholder="Email">
    <button type="submit">Submit</button>
</form>

process.php

<?php
    if ($_SERVER["REQUEST_METHOD"] === "POST") {
        $name = htmlspecialchars($_POST['name']);
        $email = htmlspecialchars($_POST['email']);

        echo "<h2>Thank you, $name!</h2>";
        echo "<p>We'll contact you at $email</p>";
    }
?>
💡 htmlspecialchars() prevents XSS attacks by escaping special characters. 💡 htmlspecialchars() विशेष वर्णों को एस्केप करके XSS हमलों से बचाता है।

C. Form Validation C. फ़ॉर्म वैलिडेशन 

<?php
    $errors = [];
    if ($_SERVER["REQUEST_METHOD"] === "POST") {
        if (empty($_POST['name'])) {
            $errors[] = "Name is required";
        }
        if (!filter_var($_POST['email'], FILTER_VALIDATE_EMAIL)) {
            $errors[] = "Invalid email";
        }
    }
?>

<form method="POST">
    <input type="text" name="name">
    <input type="email" name="email">
    <button>Submit</button>
</form>

<?php
    foreach ($errors as $e) {
        echo "<p style='color:red'>$e</p>";
    }
?>

PART 5: Database with PDO (Best Practice) भाग 5: PDO के साथ डेटाबेस (सर्वोत्तम प्रथा) 

<?php
    $host = "localhost";
    $db   = "mydb";
    $user = "root";
    $pass = "";

    try {
        $pdo = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4", $user, $pass);
        $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    } catch (PDOException $e) {
        die("Connection failed: " . $e->getMessage());
    }

    // INSERT (prepared statement — prevents SQL injection)
    $stmt = $pdo->prepare("INSERT INTO users (name, email) VALUES (?, ?)");
    $stmt->execute(["John", "john@example.com"]);

    // SELECT
    $stmt = $pdo->query("SELECT * FROM users");
    while ($row = $stmt->fetch(PDO::FETCH_ASSOC)) {
        echo $row['name'];
    }
?>
⚠️ Never build SQL with string concatenation — always use prepared statements. ⚠️ SQL को स्ट्रिंग जोड़कर कभी न बनाएँ — हमेशा prepared statements का उपयोग करें।

PART 6: Complete Mini Project — Login System भाग 6: पूरा मिनी प्रोजेक्ट — लॉगिन सिस्टम

login.php

<?php
    session_start();
    if (isset($_SESSION['user'])) {
        header("Location: dashboard.php");
        exit;
    }
?>
<form method="POST" action="auth.php">
    <input type="text" name="username" placeholder="Username" required>
    <input type="password" name="password" placeholder="Password" required>
    <button type="submit">Login</button>
</form>

auth.php

<?php
    session_start();
    $u = $_POST['username'] ?? '';
    $p = $_POST['password'] ?? '';

    // Demo only — real apps use database + password_hash()
    if ($u === "admin" && $p === "1234") {
        $_SESSION['user'] = $u;
        header("Location: dashboard.php");
        exit;
    } else {
        echo "Invalid credentials";
    }
?>

dashboard.php

<?php
    session_start();
    if (!isset($_SESSION['user'])) {
        header("Location: login.php");
        exit;
    }
    echo "<h1>Hello, " . htmlspecialchars($_SESSION['user']) . "</h1>";
    echo '<a href="logout.php">Logout</a>';
?>

logout.php

<?php
    session_start();
    session_destroy();
    header("Location: login.php");
?>
