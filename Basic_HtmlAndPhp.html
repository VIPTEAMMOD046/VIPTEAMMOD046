HTML & PHP — A to Z Guide

A complete beginner-to-advanced walkthrough of HTML (structure) and PHP (server-side logic).

PART 1: HTML (HyperText Markup Language)

HTML is the skeleton of a web page. It defines structure and content.

A. Basic HTML Document Structure

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>
</head>
<body>
    <h1>Hello World</h1>
</body>
</html>
  • <!DOCTYPE html> → tells browser it's HTML5
  • <html> → root element
  • <head> → metadata (not visible)
  • <body> → visible content

B. Common Tags

TagPurpose
<h1>–<h6>Headings
<p>Paragraph
<a href="">Link
<img src="" alt="">Image
<ul>, <ol>, <li>Lists
<div>Block container
<span>Inline container
<br>Line break
<hr>Horizontal rule

C. Forms (key for PHP)

<form action="submit.php" method="POST">
    <label>Name:</label>
    <input type="text" name="username" required>

    <label>Email:</label>
    <input type="email" name="email">

    <label>Password:</label>
    <input type="password" name="password">

    <button type="submit">Send</button>
</form>
  • action → where data goes
  • method → GET (visible in URL) or POST (hidden, secure)

D. Tables, Media, Semantics

    <tr><th>Name</th><th>Age</th></tr>

PART 2: PHP (PHP: Hypertext Preprocessor)

PHP is a server-side language — it runs on the server and sends HTML to the browser.

A. Basic PHP Syntax

<?php
    echo "Hello World";
?>
  • Starts with <?php, ends with ?>
  • Statements end with ;
  • Can be mixed with HTML

B. Variables & Data Types

<?php
    $name = "John";       // string
    $age = 25;            // integer
    $price = 9.99;        // float
    $isActive = true;     // boolean
    $items = [1, 2, 3];   // array
    $user = null;         // null
?>
  • Variables start with $
  • No type declaration needed (loosely typed)

C. Operators

<?php
    $a = 10 + 5;      // 15
    $b = 10 % 3;      // 1 (modulus)
    $c = "Hi" . " there";   // concatenation with .

    // Comparison
    $x == $y;   // equal value
    $x === $y;  // equal value AND type
    $x != $y;   // not equal
    $x > $y;    // greater than
?>

D. Conditionals

<?php
    if ($age >= 18) {
        echo "Adult";
    } elseif ($age >= 13) {
        echo "Teen";
    } else {
        echo "Child";
    }

    // Switch
    switch ($color) {
        case "red": echo "Stop"; break;
        case "green": echo "Go"; break;
        default: echo "Unknown";
    }
?>

E. Loops

<?php
    for ($i = 0; $i < 5; $i++) {
        echo $i;
    }

    $fruits = ["apple", "banana", "cherry"];
    foreach ($fruits as $fruit) {
        echo $fruit;
    }

    $n = 0;
    while ($n < 3) {
        echo $n;
        $n++;
    }
?>

F. Functions

<?php
    function greet($name) {
        return "Hello, $name!";
    }

    echo greet("Alice");   // Hello, Alice!

    // Default parameter
    function add($a, $b = 10) {
        return $a + $b;
    }
?>

G. Arrays

<?php
    // Indexed
    $colors = ["red", "green", "blue"];
    echo $colors[0];    // red

    // Associative
    $user = [
        "name" => "John",
        "age" => 25,
        "email" => "john@example.com"
    ];
    echo $user["name"];   // John

    // Useful functions
    count($colors);        // 3
    array_push($colors, "yellow");
    array_keys($user);
    array_values($user);
?>

H. Superglobals (Very Important!)

VariableUse
$_GETData from URL/GET forms
$_POSTData from POST forms
$_SESSIONUser session data
$_COOKIECookies
$_FILESUploaded files
$_SERVERServer info
<?php
    $name = $_POST['username'] ?? '';
    echo "Welcome, $name";
?>

B. Processing a Form

form.html

<form action="process.php" method="POST">
    <input type="text" name="name" placeholder="Your name">
    <input type="email" name="email" placeholder="Email">
    <button type="submit">Submit</button>
</form>

process.php

<?php
    if ($_SERVER["REQUEST_METHOD"] === "POST") {
        $name = htmlspecialchars($_POST['name']);
        $email = htmlspecialchars($_POST['email']);

        echo "<h2>Thank you, $name!</h2>";
        echo "<p>We'll contact you at $email</p>";
    }
?>
💡 htmlspecialchars() prevents XSS attacks by escaping special characters.

C. Form Validation

<?php
    $errors = [];
    if ($_SERVER["REQUEST_METHOD"] === "POST") {
        if (empty($_POST['name'])) {
            $errors[] = "Name is required";
        }
        if (!filter_var($_POST['email'], FILTER_VALIDATE_EMAIL)) {
            $errors[] = "Invalid email";
        }
    }
?>

<form method="POST">
    <input type="text" name="name">
    <input type="email" name="email">
    <button>Submit</button>
</form>

<?php
    foreach ($errors as $e) {
        echo "<p style='color:red'>$e</p>";
    }
?>

PART 4: Sessions & Cookies

<?php
    session_start();

    // Store login info
    $_SESSION['user_id'] = 42;
    $_SESSION['username'] = "John";

    // Check if logged in
    if (!isset($_SESSION['user_id'])) {
        header("Location: login.php");
        exit;
    }

    // Logout
    session_destroy();
?>

Cookies:

<?php
    setcookie("theme", "dark", time() + 86400, "/");   // 1 day
    echo $_COOKIE['theme'] ?? "light";
?>

PART 5: Database with PDO (Best Practice)

<?php
    $host = "localhost";
    $db   = "mydb";
    $user = "root";
    $pass = "";

    try {
        $pdo = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4", $user, $pass);
        $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    } catch (PDOException $e) {
        die("Connection failed: " . $e->getMessage());
    }

    // INSERT (prepared statement — prevents SQL injection)
    $stmt = $pdo->prepare("INSERT INTO users (name, email) VALUES (?, ?)");
    $stmt->execute(["John", "john@example.com"]);

    // SELECT
    $stmt = $pdo->query("SELECT * FROM users");
    while ($row = $stmt->fetch(PDO::FETCH_ASSOC)) {
        echo $row['name'];
    }
?>
⚠️ Never build SQL with string concatenation — always use prepared statements.

PART 6: Complete Mini Project — Login System

login.php

<?php
    session_start();
    if (isset($_SESSION['user'])) {
        header("Location: dashboard.php");
        exit;
    }
?>
<form method="POST" action="auth.php">
    <input type="text" name="username" placeholder="Username" required>
    <input type="password" name="password" placeholder="Password" required>
    <button type="submit">Login</button>
</form>

auth.php

<?php
    session_start();
    $u = $_POST['username'] ?? '';
    $p = $_POST['password'] ?? '';

    // Demo only — real apps use database + password_hash()
    if ($u === "admin" && $p === "1234") {
        $_SESSION['user'] = $u;
        header("Location: dashboard.php");
        exit;
    } else {
        echo "Invalid credentials";
    }
?>

dashboard.php

<?php
    session_start();
    if (!isset($_SESSION['user'])) {
        header("Location: login.php");
        exit;
    }
    echo "<h1>Hello, " . htmlspecialchars($_SESSION['user']) . "</h1>";
    echo '<a href="logout.php">Logout</a>';
?>

logout.php

<?php
    session_start();
    session_destroy();
    header("Location: login.php");
?>
